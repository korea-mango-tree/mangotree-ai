## 6. 사실관계 정정 (1차 보고 대비)
- `LEAD_ENDPOINT`는 `main`에서 **빈 값**이다. 1차 보고의 "값이 있음"은 마스킹 명령이 빈 문자열을 잘못 읽은 결과다.
- 그래서 상담 신청은 메일 앱을 여는 방식으로만 동작한다. 사용자가 메일 앱에서 **보내기를 눌러야 접수가 끝난다.** 완료 화면에도 「열린 메일 앱에서 보내기를 눌러야 접수가 완료됩니다」라고 안내되며, 이번 변경에서 바꾸지 않았다.
- 결제 링크(`REPORT_PAYMENT_URL`), 기업 검색(`COMPANY_SEARCH_ENDPOINT`), `KAKAO_JS_KEY`도 빈 값이다. 새로 구현하지 않았고 키도 요구하지 않았다.

사용자 지시: "부분 개선하지 말고 인덱스 메인 페이지부터 대대적으로 리뉴얼하면서 새롭게 만들어줘." 기존 카드·폰 목업·섹션 배열을 다듬는 수준이 아니라, `index.html`의 정보 구조·레이아웃·아트디렉션을 새로 만들었다.

- **포지셔닝**: AI와 디자인·개발을 연결하는 커머스 파트너.
  - 헤드라인: 「커머스의 다음 장을 함께 만듭니다.」
  - 주 CTA는 무료 AI 진단 하나, 보조는 텍스트 링크 「프로젝트 상담하기」.
- **아트디렉션**: 차콜(#161616) · 웜 아이보리(#F5F0E6) · 망고 옐로(브랜드 #FEE500)의 면 분할, 한글 대형 타입(1440px에서 약 104px, 390px에서 약 44px), 실제 작업물이 주인공.
  - 스크롤 연출·회전 슬라이드·카운트업은 없다.
  - 마우스를 올려야만 보이는 정보도 없다.
- **섹션 6개**
  1. 차콜 첫 화면 + 실제 작업물 콜라주(제품 촬영·상세페이지·푸드 촬영·홈페이지)
  2. WHAT WE DO: Create / Connect / Grow 대형 번호 행. 6개 AI 제품은 `modules.html#mod-0~5` 태그로 연결
  3. SELECTED WORK: 오늘밤엔(대형), 커머스 앱 구축 사례, 상세페이지 디자인
  4. HOW WE WORK: 진단 → 설계·구현 → 운영 개선, 「AI가 속도를 내고, 사람이 끝까지 만듭니다」
  5. 직접 운영하는 플랫폼 목록 + EXPLORE 링크(AI 제품·AI 모듈·활용사례·요금제)
  6. 노란 마지막 CTA, 그 아래 공통 푸터
- **홈에서 걷어낸 것**: 회전 폰 목업, 노란 둥근 사각형, 작은 지표 3칸, 서비스 그림 카드 6개, 샘플 대시보드, 티글 판매 상품, 요금제 미니 카드, 채널 로고 띠. 모두 전용 페이지(products·modules·platforms·pricing·usecase) 링크로 정리했다.

## 17. AI 모듈·요금제·무료진단 페이지 정리 (modules.html, pricing.html, diagnosis.html)

메인과 같은 차콜·웜 아이보리·망고 옐로, 큰 한글 제목, 넓은 여백으로 맞췄다. 새 기능이나 새 수치·가격·고객은 넣지 않았다.

**구조**
- **modules·pricing**: 페이지 안 `<style>`을 지우고 `base.css → site.css → sub.css` 공통 구조로 옮겼다(`body.sub`, `x-` 접두사).

  - 결과 화면의 의미색(개선 필요=주황, 양호=초록)은 정보를 전하므로 유지했다.

**사전 QA 지적 4건 수정**
1. **요금제 「진단 리포트 예시」**
   - 숙박 관리자 화면 이미지(`0555685655e2…`)를 뺐다.
   - 그 자리에 실제 진단 방식을 3단계로 설명한다: 기업명으로 시작 → 선택형 설문 최대 14문항(모름 선택 가능) → 정해진 규칙으로 계산한 개선 순서.
   - 4개 플랜(AI START·COMMERCE·GROWTH·ENTERPRISE)에는 금액을 적지 않고 「금액: 범위 확인 후 견적」으로 표기했다.
   - 플랜마다 상담 버튼(메일 제목 `[망고트리 AI+] {플랜} 플랜 상담`)을 달았다.
2. **AI 모듈 상세 창 아이콘**
   - `elIcon.textContent=icon.textContent`가 SVG를 빈 글자로 덮어쓰던 문제를 고쳤다. 지금은 원본 SVG를 `cloneNode(true)`로 복제해 넣는다.
   - 카드 아이콘이 검게 채워지던 문제도 고쳤다. 인라인 CSS를 지우면서 `.ico` 선 스타일이 빠졌던 것이라 `sub.css`에 복구했다.
3. **진단 「정밀 리포트 미리보기」**
   - 태그를 「설문 기반 미리보기」로 바꿨다.
   - 미리보기 지표는 방금 입력한 설문 답변으로만 계산했고, 온라인 노출·판매 채널·평판·경쟁사 조사는 아직 하지 않았다고 명시했다.
   - 기업 조사는 「상담 후 진행」으로 표기했다. 가격 문구는 「신청하면 상담으로 범위와 일정을 정한 뒤, 조사와 담당자 검수를 거쳐 보내드립니다」이다.
   - 위키백과 대체 검색, 메일 상담, 리포트 신청을 서버 접수나 결제로 표현하지 않는다.
   - `LEAD_ENDPOINT`·`COMPANY_SEARCH_ENDPOINT`·`REPORT_PAYMENT_URL`·`REPORT_PRICE`는 빈 값 그대로다.
4. **앵커 착지 위치**
   - `#cases`·`#usecase`가 글꼴·이미지 로드 뒤 24px 어긋나던 문제를 고쳤다.
     - `site.js`가 주소에 해시가 있으면 `document.fonts.ready`와 `load` 시점에 한 번 더 맞춘다.
     - 사용자가 먼저 스크롤·키를 누르면 다시 맞추지 않는다.
   - 카드 단위 앵커(`#mod-N`·`#tigl`)는 `scroll-padding-top:80px`에 `scroll-margin-top:96px`이 겹쳐 176px에 착지했다. 겹친 값을 지워 모든 앵커가 80px로 같다.

## 20. 활용사례 BEFORE / AFTER 재구성 (usecase.html, assets/usecase.css)

- **상단**
  - 제목을 「도입 전과 후, 달라지는 일하는 방식」으로, 구역 제목을 「네 가지 고민, 도입 전과 후」로 바꿨다.
  - 비교 사례의 성격을 한 줄로 밝힌다: 「도입 전·후 업무 흐름을 비교한 예시입니다. 실제 적용 범위는 상담에서 정합니다.」 같은 프로젝트의 전·후 자료가 없으므로 고객 실적처럼 보이지 않게 하려는 것이다.
- **4개 사례 구조**
  - 고민 문구와 제목 아래에 BEFORE(도입 전 업무 예시)와 AFTER(도입 후 제안 흐름) 카드를 같은 크기로 나란히 둔다. 860px 이하에서는 도입 전 → 도입 후 순서로 세로 배치한다.
  - 두 카드는 각각 흐름 칩 3단계, 같은 크기의 그림 영역, 짧은 문구 3개로 이뤄진다. 아래에는 「변화 요약」 한 줄과 관련 제품 링크가 온다.
  - 색은 BEFORE 회색, AFTER 망고 옐로다. 「BEFORE·도입 전 업무 예시」「AFTER·도입 후 제안 흐름」 글자로도 구분한다.
- **BEFORE 그림**: 실제 고객 화면이 아닌 HTML·CSS 도식이다. 흐리게 하거나 저화질 이미지를 쓰지 않았다.
  1. 같은 크기로 나열된 상품 정보
  2. 상품마다 처음부터 반복하는 기획·촬영·편집
  3. 비슷한 질문을 담당자 1명이 하나씩 답변
  4. 흩어진 매출 엑셀·광고 관리자·주문 내역·메모
- **AFTER 그림**
  1. 스마트카드태그 상세페이지(실제 작업물, `contain`)
  2. 페이지메이커 AI 이미지 화면
  3. 문의 분류 → 먼저 응대 → 상담원 연결 HTML·CSS 도식. 기획용 AI 기획 스크린샷을 상담 화면으로 오해하지 않도록 바꿨다.
  4. 실적 리포트 확대 크롭
- 숫자로 된 개선 효과는 넣지 않았다.
- **사용자 추가 지시로 정리한 것**
  - 이미지 밑의 출처·원본 보기 링크·캡처 날짜·「실제 화면/실제 작업물」 배지·긴 부연 설명을 모두 지웠다.
  - 이미지의 `alt`와, 이미지를 누르면 원본이 새 창으로 열리는 링크는 그대로다.
  - WORKS 카드는 분류와 작품명만 남겼고(출처 문구 삭제), 구역 설명을 한 줄로 줄였다.
- 이미지 파일은 바꾸지 않았다. 다른 페이지와 공통 CSS(`sub.css`의 이전 `.x-uc*` 규칙 포함)도 그대로다. 출처·라이선스 기록은 이 문서 19절과 각 manifest에 남아 있다.
- **검증 (1440·390·320)**

  - BEFORE/AFTER 4쌍은 1440에서 같은 크기(624×835)다.
