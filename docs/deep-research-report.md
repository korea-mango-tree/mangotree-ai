# 정밀 진단 리포트 — 딥리서치 작성 가이드

기업진단 페이지에서 **정밀 진단 리포트**를 신청(또는 결제)하면 담당자 메일로 신청서가 옵니다.
신청 메일 맨 아래 `── 딥리서치 요청문` 블록을 복사해 딥리서치 기능에 그대로 붙여 넣으면 리포트 초안이 만들어집니다.

- Claude: 대화창에서 **Research(딥리서치)** 를 켜고 요청문을 붙여 넣기
- Claude Code: `/deep-research` 스킬 또는 "딥리서치로 조사해줘" 뒤에 요청문 붙여 넣기

초안은 담당자가 사실 여부와 출처를 확인한 뒤 고객에게 보냅니다. 사이트에는 서버가 없어 자동 발송되지 않습니다.

## 진행 순서

1. 신청 메일 확인 → 결제 여부 확인
2. `── 딥리서치 요청문` 블록 전체 복사 → 딥리서치 실행 (보통 10–30분)
3. 초안 검수 (아래 체크리스트)
4. 리포트를 PDF나 문서 링크로 고객에게 발송, 1:1 결과 설명 일정 잡기

## 요청문 구성

신청 메일의 요청문은 아래 틀에 진단 데이터가 채워진 형태입니다. 메일이 없을 때는 이 틀을 직접 채워 써도 됩니다.

```
[망고트리 정밀 진단 리포트 — 딥리서치 요청]
조사 대상: {기업명} ({검색 업종 분류}, {주소})
알려진 홈페이지: {URL 또는 없음}
진단 목적: {목적} / 업종: {업종}
진단 결과: 판매 기반 현황점수 {점수}, 필요도 상세페이지 {D}·홈페이지 {W}·촬영 {P}·브랜드 {B}·마케팅 {M}
추천 순서: {추천 서비스}
약한 지표: {준비도 0점인 지표들}

조사 항목
1. 온라인 노출: 검색 결과, 지도·플레이스 등록, 공식 홈페이지 상태(모바일·최신성·문의 동선)
2. 판매 채널: 자사몰, 스마트스토어·쿠팡 등 오픈마켓, 예약 플랫폼 입점 여부와 상세페이지 품질
3. 콘텐츠·브랜드: 대표 사진·영상 수준, 로고·디자인 일관성, SNS 운영 빈도
4. 평판: 공개 리뷰·언론 기사의 주요 반응(긍정·부정 각 3개 이내)
5. 경쟁사: 같은 업종·지역 경쟁사 3곳의 채널·콘텐츠 비교
6. 업종 동향: 최근 1년 온라인 판매·홍보 트렌드 3가지

출력 형식
A. 요약(5줄)
B. 정량 평가: 12개 지표(상세페이지 보유, 구매 이유 전달, 홈페이지 최신성, 모바일 전환 동선,
   대표 사진 확보, 사진 연출력, 브랜드 기준, 디자인 일관성, 온라인 노출·운영, 성과 측정,
   자료·담당자 준비, 반복 업무 여유)를 0–100으로, 진단 답변과 웹 조사 근거를 함께 표기
C. 정성 평가: 강점 3개, 약점 3개, 영역별 개선 코멘트
D. 경쟁사 비교표
E. 12주 실행 로드맵(1–4주, 5–8주, 9–12주) — 추천 순서를 바꾸지 말 것
F. 출처 목록(링크)

규칙
- 모든 사실에 출처 링크를 달고, 확인되지 않은 내용은 "추정"으로 표시
- 매출·전환율·비용 절감 수치를 만들지 말 것
- 대표자·직원 등 개인정보는 수집하지 말 것
- 진단 답변과 웹 조사 결과가 다르면 둘 다 적고 차이를 설명
```

## 검수 체크리스트

- [ ] 조사 대상이 신청 기업과 같은 회사인가 (동명 기업 주의)
- [ ] 모든 수치·사실에 출처 링크가 있는가
- [ ] 매출 증가율 등 근거 없는 성과 수치가 없는가
- [ ] 로드맵 순서가 진단 결과의 추천 순서와 같은가
- [ ] 개인정보가 들어가 있지 않은가
